🚀 Features :

App Management : Create, Update, and Delete apps with real-time synchronization between SQL and OpenSearch.

Advanced Search : Fuzzy search capabilities across app names and descriptions.

Analytics : Aggregated statistics for total installations per author using OpenSearch Aggregations.

User System : Secure Sign-up and Sign-in functionality.

Installation & Reviews: Track app installs and user ratings with automated rating sync.

🏗️ Technology Stack :

Framework : Spring Boot 3.2.0

Language : Java 17

Primary Database : PostgreSQL

Search Engine : OpenSearch 2.11

Containerization : Docker & Docker Compose

Build Tool : Maven
